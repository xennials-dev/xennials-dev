## 🌟 Overview

Xennials bridges analog intuition with digital precision, delivering high-performance AI automation workflows, agentic AI frameworks, and full-stack web platforms.

### Core Features

- **🏠 Home Portal (`index.html`)**: Interactive hero, services matrix, interactive ROI calculator, case studies, dynamic theme engine, and contact hub.
- **📖 Insights Blog (`blog.html`)**: In-depth articles and architecture breakdowns for autonomous agents, local LLM orchestration, and enterprise workflow engines.
- **⚡ App Playground (`playground.html`)**: Interactive sandboxes including AI Workflow Builder preview, JSON/cURL test benches, and Agent telemetry simulators.
- **🎨 Design System (`styles.css`, `script.js`)**: Modern glassmorphism, fluid responsive layouts, customizable color palettes, and micro-interactions.

## 🚀 Deployment & Hosting

This project is deployed on **Netlify** under:
- **Custom Domain**: `https://xennials.tech/`
- **Netlify App Name**: `steady-unicorn-66b93d`
- **Site ID**: `cf70efbf-a643-4fda-a643-811cdccc9e28`

Deploy commands:
```bash
# Start local dev server (port 3000)
npm run dev

# Build for production
npm run build

# Deploy to preview
npx netlify deploy

# Deploy to production
npx netlify deploy --prod
```
